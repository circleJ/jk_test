# Configure display language

Read the current setting with get_display_language.

Set a language only when the request names exactly one supported code: en, es, fr, de, ja, zh, ko, pt. Names and tags such as Español, ja-JP, and zh-CN map to those codes.

"Configure Display Language" with no language means ask which code to set.

An unknown language is not a guess. List the supported codes and leave the setting unchanged.
